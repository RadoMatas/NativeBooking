# NativeBooking Design System


## Inspiration

Use principles from:

- Airbnb → hospitality and trust
- Vercel → simplicity and precision
- Stripe → clarity and confidence
- Apple → premium simplicity


Do not copy them.

Learn from their principles.


# Overall Feeling

Premium hospitality software.

Clean.
Calm.
Professional.


Avoid:

- excessive gradients
- neon colors
- glass effects everywhere
- random floating cards
- AI-generated patterns


# Layout


Prefer:

- strong hierarchy
- generous whitespace
- clear sections
- real product screenshots
- meaningful visuals


Avoid:

- every section centered
- repetitive cards
- giant empty hero sections


# Typography


Priorities:

1. readability
2. hierarchy
3. confidence


Use:

- strong headings
- short paragraphs
- comfortable line spacing


Avoid:

- too many font sizes
- decorative fonts


# Colors


Style:

- neutral backgrounds
- trustworthy primary color
- limited accent colors


Never introduce new colors without reason.


# Components


Buttons:

Should feel:

- clear
- confident
- easy to click


Cards:

Should:

- support information
- not exist only for decoration


Forms:

Should:

- reduce anxiety
- explain what happens next


# Animation


Use:

- subtle fade
- small movement
- hover feedback


Timing:

150-250ms


Avoid:

- bouncing
- flashy transitions
- unnecessary motion


# Responsive


Every design must work:

- desktop
- tablet
- mobile


Mobile is not a smaller desktop.
